### 1. Анализ Данных о Сердечных Заболеваниях (`здравие1.ipynb`)

Этот ноутбук посвящен исследовательскому анализу данных (EDA) и предварительной обработке популярного датасета **Heart Disease UCI** (Кливлендская база данных).

**Цели проекта:**
*   Загрузка и первичный осмотр датасета.
*   Изучение структуры данных, типов признаков и их статистических характеристик.
*   Выявление закономерностей и взаимосвязей между различными медицинскими показателями (возраст, пол, уровень холестерина, тип боли в груди и т.д.) и наличием сердечного заболевания (`target`).

**Основные шаги в ноутбуке:**
*   Импорт библиотеки `pandas` для работы с данными.
*   Чтение CSV-файла `Heart_disease_cleveland_new.csv`.
*   Вывод первых и последних строк датафрейма для ознакомления.
*   Проверка размерности данных (`shape`).
*   Получение описательной статистики по всем числовым признакам (`describe`), что позволяет оценить распределение, средние значения и разброс.

**Навыки и технологии:**
*   Python 3
*   Pandas
*   Google Colab

### 2. Обработка и Анализ DICOM-Изображений (`здравие2.ipynb`)

Этот ноутбук демонстрирует полный пайплайн обработки и анализа медицинского изображения, полученного методом магнитно-резонансной томографии (МРТ), в формате DICOM.

**Цели проекта:**
*   Чтение и визуализация DICOM-файла.
*   Улучшение визуального качества изображения с помощью различных методов.
*   Сегментация изображения для выделения интересующих областей.
*   Обнаружение границ и контуров объектов на изображении.

**Основные шаги в ноутбуке:**
1.  **Установка и импорт библиотек:** Устанавливается и импортируется библиотека `pydicom` для работы с DICOM-файлами, а также `numpy`, `matplotlib`, `opencv-python` и `PIL`.
2.  **Чтение и визуализация:** Загружается `MR.1.2....dcm` файл, извлекается массив пикселей и отображается оригинальное изображение в градациях серого.
3.  **Нормализация (Histogram Stretching):** Реализована функция для линейного растяжения гистограммы, что повышает контрастность и улучшает видимость деталей.
4.  **Выравнивание гистограммы (Histogram Equalization):** Применяется метод `cv2.equalizeHist` для более равномерного распределения яркости.
5.  **Гамма-коррекция:** Используется степенное преобразование для дальнейшего усиления контраста и изменения общей яркости изображения.
6.  **Пороговая обработка (Thresholding):** Применяется бинаризация изображения по порогу для разделения его на "объекты" и "фон".
7.  **Поиск и отрисовка контуров:** С помощью `cv2.findContours` и `cv2.drawContours` находятся и отображаются внешние контуры сегментированных объектов.
8.  **Детектор границ Кэнни (Canny Edge Detection):** Применяется популярный алгоритм для выделения тонких границ на изображении.

**Навыки и технологии:**
*   Python 3
*   Pydicom
*   OpenCV (cv2)
*   NumPy
*   Matplotlib
*   Pillow (PIL)
